# 创意方法

创意总监的通用方法库：观众为什么会看（机制），和怎样产出点子（手法）。本账号验证过哪些有效，看「本账号的经验」。

系统的创意方法（SIT、TRIZ、横向思维等）见技能 creative-director（Serge Shima，CC BY 4.0）：它的自评可以用来改稿，最终选哪个仍由创意评审决定；引用它的案例和方法原文时注明出处。

## 机制：观众为什么停下、看完、转发

| 机制 | 一句话 | 常见做法 |
|---|---|---|
| 预期反转 | 先建立熟悉的预期，在关键点翻过来 | 前 2 秒交代"应该会发生什么"，结尾给出相反或更好的结果 |
| 升级失控 | 一件小事一步步升级到荒诞 | 每一步都比上一步大一点，节奏越来越快 |
| 荒诞冲突 | 两样不该碰在一起的东西被认真对待 | 用正经的拍法拍离谱的事 |
| 认知颠覆 | 揭示观众以为知道、其实不知道的事 | 先抛常识，再给反常识的证据 |
| 身份错位 | 人物出现在不属于自己的场景或身份里 | 让角色用自己的习惯处理陌生的处境 |
| 情绪反差 | 画面和声音、外表和内在形成反差 | 治愈的画面配紧张的声音，或反过来 |
| 视觉奇观 | 一眼就想看完的画面 | 规模、质感、技术或不可能的画面，第 1 秒就给 |
| 过程满足 | 从乱到整、从无到有的完整过程 | 压缩过程，保留关键变化和最终对比 |
| 代入共鸣 | 观众在里面看到自己 | 具体的处境、关系、小心思，越具体越像自己 |
| 挑战悬念 | 先定目标或规则，让观众等结果 | 开头说清挑战，中途制造波折，结尾揭晓 |
| 系列追更 | 固定人物或规则，每集一个新问题 | 每集独立成立，结尾留一个新处境 |
| 评论驱动 | 留出观众想补充、争论或点续集的空间 | 留一个有争议的选择或未完成的小悬念 |

## 手法：怎样产出点子

- **机制迁移**：把原作写成一句机制（例如"预期建立 → 规则反转 → 荒诞结果"），再换主体、换场景、换关系套用。
- **强制组合**：列出"本账号角色 × 近期热点 × 内容形式"三栏，随机组合，挑出意外又成立的组合。
- **反向思考**：把赛道里最常见的拍法反过来：主角换成配角、结果放到开头、严肃话题用轻松的方式讲。
- **推到极端**：把一个属性推到最大或最小：最长、最快、最贵、最小的场景。
- **约束创作**：加限制逼出新形式：一个镜头、没有台词、7 秒、只用一种颜色。
- **视角切换**：换成物件、动物、旁观者或观众的视角讲同一件事。
- **替换与删减**：替换场景、道具或关系；删掉一个"必须有"的元素，看还成立吗。
- **失败预演**：先假设这条没人看，写下三个原因，再逐个改掉。

## AI 生成内容的取舍

- 多用 AI 擅长的：不可能的画面、稳定的固定角色、风格化的质感、大场面。
- 少用 AI 容易崩的：复杂的手部动作、多人细致互动、画面里的长段文字、需要精确物理的连续动作。
- 把创意难点放在一个镜头里，其他镜头尽量简单，生成成本和失败率都会降下来。
