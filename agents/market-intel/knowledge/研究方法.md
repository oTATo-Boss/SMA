# 研究方法

市场研究的通用做法。找异常作品和挖评论参考了 ScrapeCreators 的 outlier-post-finder、comment-mining 技能（MIT 许可）的方法；数据按本步骤的权限获取，不调用它们的付费接口。

## 找异常作品

1. 先定作者的常态：同一平台、同类形式的近 10–20 条作品，取主要指标的**中位数**；不用平均数，免得一条爆款把常态拉高。
2. 倍数 = 这条作品的指标 ÷ 常态中位数，写进 `outlier_ratio`。
3. 分档：5 倍以上是大爆款，2–5 倍明显超常，1.5–2 倍小幅超常；优先收 3 倍以上的。
4. 不跨平台、不跨账号混算常态；拿不到作者近期作品时，倍数写 null 并说明原因。
5. 样本少于 10 条，结论只供参考。

## 主要指标

- 有播放量就用播放量；看不到时用点赞、评论、收藏（或转发）之和，并在 `baseline.description` 写明口径。
- 原始数字都保留在 `metrics` 里，组合口径另外说明。
- 各平台公开的指标不同（例如小红书一般看不到播放量），只写看得到的。

## 挖评论

把有用的评论归类：提问、反对、抱怨、夸奖、困惑、想要续集或同款、购买意向、争议、梗。按出现次数和强烈程度归纳主题，保留原话。一条很响的评论不等于普遍需求；水军和广告不算观众信号。归纳结果写进机会的 `audience_signal`。

## 拆解作品

| 看什么 | 记什么 |
|---|---|
| 前 3 秒 | 第一个画面、第一句话或字幕、为什么会停下 |
| 节拍 | 每一段大约在第几秒、发生了什么 |
| 情绪 | 怎么起伏，反转或笑点在哪 |
| 形式 | 画面风格、剪辑节奏、声音、字幕 |
| 包装 | 标题、封面字、话题 |
| 观众 | 评论里在问什么、要什么 |

## 迁移停在机制层面

- 可以借：节拍结构、钩子类型、情绪曲线、选题角度、形式规则（例如"一个镜头拍完"）。
- 不能借：别人的角色、固定人设、世界观、招牌台词、具体画面和文案。
- `transferable` 用一句机制描述，例如"预期建立 → 规则反转 → 荒诞结果"。
