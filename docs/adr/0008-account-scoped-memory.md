# ADR-0008 记忆按账号存，不用客户端全局记忆

- 状态：已采纳（2026-10-15）
- 相关：[06 工作区与数据](../design/06-workspace-and-data.md) 第 4 节、[04 引擎适配](../design/04-engines.md) 第 4 节

## 背景

AI-SMA 的测试中，Codex 的全局记忆把其他项目的信息带进了账号项目。经验又必须积累，才能让系统越用越准。

## 决定

经验只存在账号工作区的 `memory/<包 id>.md`，分"已验证"和"假设"；只能通过增长分析的经验更新（经校验）或本人的明确指令写入。调用引擎时不加载用户配置，客户端的全局记忆不读也不写。

## 代价与影响

- 账号之间不会串信息；经验有证据和样本数。
- 跨账号通用的经验不能自动共享；需要时由本人决定是否写进 Agent 包的知识。

## 考虑过的其他方案

- 用客户端自带的记忆：省事，但无法隔离，也无法校验。
