# ADR-0002 核心用 Python

- 状态：已采纳（2026-10-15）
- 相关：[00 总体设计](../design/00-overview.md) 第 10 节

## 背景

本人对语言没有偏好。SMA 的核心是编排、校验、状态和媒体处理；引擎以子进程调用，和语言无关；以后有本地前端。

## 决定

核心用 Python 3.11+，用 uv 管理环境；以后的前端单独用 TypeScript，通过本地接口读写同一套状态。

## 代价与影响

- 媒体处理（ffmpeg 封装、转写）、数据分析、JSON Schema 校验和 MCP 都有成熟的 Python 库。
- 前后端是两种语言；接口要定义清楚，前端开始前写接口规范。

## 考虑过的其他方案

- 全部用 TypeScript：MCP 和 Codex app-server 的 TypeScript 绑定很顺，前后端一种语言；但媒体和数据处理的生态弱一些。
