# ADR-0009 总控是代码，不是 LLM 角色

- 状态：已采纳（2026-10-15）
- 相关：[03 流程与编排](../design/03-workflow.md)

## 背景

多 Agent 系统常见的做法是让一个"总控 Agent"自由调度其他 Agent。但流程、上限、策略和阻塞判断交给模型，正是 AI-SMA 测试里跑偏的原因之一。

## 决定

流程、并行、循环、上限、策略和阻塞判断由代码执行。需要临场判断的地方（例如研究方向、创意方法组合），由规划 Agent 交出提议，代码按流程约束校验后采用；规划 Agent 不能改变步骤、上限和策略。

## 代价与影响

- 行为可预测、可复现、可测试；约束不会被模型绕开。
- 灵活性来自流程定义和规划提议，新的协作方式要先写进流程。

## 考虑过的其他方案

- LLM 总控自由调度：灵活，但不可预测，难以保证约束和复现。
