# ADR-0004 工具走 MCP，红线即能力

- 状态：已采纳（2026-10-15）
- 相关：[05 工具与策略](../design/05-tools-and-policy.md)

## 背景

AI-SMA 的红线写在提示词里，测试中出现过越界。规则要由程序执行，而不是指望模型遵守。

## 决定

Agent 能用的外部能力全部由 SMA 自己的 MCP 服务提供，每一步只挂载声明的工具。不提供任何写平台的工具；浏览器研究只有读操作；写权限由沙箱和步骤目录决定；入库、写记忆、打包由代码完成。

## 代价与影响

- "不发布、不互动"这类红线从"不许做"变成"做不到"。
- 需要自己写和维护几个 MCP 服务；Agent 想要新能力时，要先加工具。

## 考虑过的其他方案

- 用引擎自带的浏览器插件：方便，但无法限制成只读，而且依赖用户配置。
