# ADR-0005 账号工作区只放数据

- 状态：已采纳（2026-10-15）
- 相关：[06 工作区与数据](../design/06-workspace-and-data.md)

## 背景

AI-SMA 每新建一个账号就复制一整套规则和工具，升级要逐个账号同步，账号之间也容易混用。

## 决定

系统（代码、Agent 包、流程、Schema、MCP 服务）装一份；每个账号一个工作区，只放这个账号的配置、策略、爆款库、经验、数据、运行记录和交付。

## 代价与影响

- 升级只升系统；账号之间天然分开。
- 账号工作区的格式要有版本，系统升级时可能需要迁移工作区。

## 考虑过的其他方案

- 沿用模板复制：上手直观，但升级和一致性成本高。
