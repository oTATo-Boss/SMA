# ADR-0006 状态用 SQLite 加文件

- 状态：已采纳（2026-10-15）
- 相关：[06 工作区与数据](../design/06-workspace-and-data.md) 第 5 节

## 背景

需要记录运行、步骤、尝试、产物、确认、检查、外部任务和评测，支持续跑和查询；现阶段单机自用。

## 决定

每个账号工作区一个 SQLite 状态库；产物和媒体以文件保存，状态库只存路径和哈希。确认和检查绑定内容哈希，对象变了就失效。

## 代价与影响

- 零运维、可备份、可直接查询。
- 以后做多用户在线时，要换成服务端数据库；表结构按可迁移的方式设计。

## 考虑过的其他方案

- 每个任务一个 JSON 文件（AI-SMA 的做法）：简单，但查询、并发和统计都不方便。
