# ADR-0007 结构化输出加四层校验

- 状态：已采纳（2026-10-15）
- 相关：[02 交接合同](../design/02-contracts.md)

## 背景

多个 Agent 之间要可靠交接；模型输出的格式、引用和元数据都可能出错或被编造。

## 决定

每种产物有 JSON Schema；引擎用它约束输出，编排层再做四层校验：Schema、语义规则、证据存在、哈希绑定。模型只填内容，产出者、输入、哈希、时间等元数据由代码填写。不通过就带着错误修复重试，次数有上限。

## 代价与影响

- 交接可靠，问题能定位到具体步骤和字段。
- Schema 要随需求演进，旧产物需要迁移。

## 考虑过的其他方案

- 自由文本交接、由下一个 Agent 自行理解：灵活，但无法自动检查，错误会一路传下去。
